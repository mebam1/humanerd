구현 개요와 연구 범위

이 저장소는 국소 접촉 표현과 전체 접촉 반응을 분리해서 학습한다는 연구 제안을 실행하는 실험실입니다. Cube에서 표현과 접촉 결합을 검증하고, 두 링크 관절체와 사족 Ant로 확장합니다. 코드의 존재나 작은 smoke 실험을 논문 가설의 입증으로 해석하지 않습니다.

무엇을 구현했는가

논리 구성 요소 역할 왜 필요한가
공통 시뮬레이터 어댑터 MuJoCo와 MuJoCo Warp를 같은 상태 계약으로 실행 백엔드 차이를 모델 차이와 혼동하지 않기 위해
Cube 접촉 시나리오 낙하, 반발, 정착, 정지, 미끄러짐, 모서리, 벽 전체 평균에 가려지는 접촉 전환 실패를 분리하기 위해
물리 표면 표현 현재 상태에서 위치·법선·표면 속도를 계산 미래 solver 정보를 유출하지 않고 접촉 상황을 제공하기 위해
계층형 모델 Point → Face/Patch → Body/Link → Articulation 떨어진 접촉의 영향을 공동 추론하기 위해
개입 및 OOD 실험 A/B 지지점, 훈련에서 제외한 접촉 조합 평균 예측 오차 이상의 인과적 접촉 결합 증거를 얻기 위해
전이 학습 scratch, 전체 적응, 하위/상위 모듈 고정 국소 표현의 재사용성과 적응 위치를 구분하기 위해
모델 기반 제어 학습 모델에서 계획하고 실제 simulator에서 실행 학습된 모델 내부 점수만 높아지는 문제를 확인하기 위해
Ant 4개 다리, 8개 actuated hinge, floating base 일반화 관절 상태 출력과 접촉 기반 제어로 확장하기 위해

실행 흐름

generate → train → evaluate → coupling / transfer / control

데이터와 체크포인트는 저장소 루트의 data/, outputs/에 생성됩니다. Docker Compose는 저장소 전체를 컨테이너의 /workspace에 bind mount합니다. 컨테이너를 삭제해도 실험 결과는 호스트에 남습니다.

연구 해석 원칙

  • 같은 trajectory가 train/test에 동시에 들어가지 않도록 분리합니다.
  • 정규화 통계는 training 데이터에서 계산합니다.
  • 자율 rollout에서는 예측한 상태로 다음 표면 표현을 다시 만듭니다.
  • NeRD-like baseline은 입력과 구조를 통제한 내부 비교군입니다. 원본 NeRD·FIGNet·RigidFormer 재현 성능으로 표기하지 않습니다.
  • 본 구현은 물리 제약을 강제로 만족시키는 neural contact solver가 아닙니다. 침투와 drift를 측정해야 합니다.
  • 실제 실행 결과와 대규모 연구 실험 계획을 구분합니다.
